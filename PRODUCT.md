# Prism

<!-- impeccable:product-schema 1 -->

## Platform

Windows desktop, Electron and React.

## Users and purpose

Prism combines everyday file browsing, media and document viewing, and persistent terminal workspaces. People can browse another folder or watch a film while their agent sessions remain visible in the same top-level tab strip.

## Constraints

Preserve existing viewers, file actions, dirty buffers, terminal ownership and truthful agent activity. Browsing location is independent of shell cwd and phone sharing. A busy shell is never retargeted by browsing. New terminals use new top-level tabs.

## Accessibility and identity

Readable text, strong contrast, usable targets and high-zoom operation are required. Preserve Prism's existing quiet dark chrome, Segoe UI, style tokens, compact tabs and selection colors. The accepted September 14 static mockup is the visual authority for the folder surface.
