# Assets

Captured from the product itself, not from a website: a scripted run of the packaged
app recorded off screen at 2880x1800 and cut into beats (`tools/showcase/`). All clips
are 1440x900, silent, all-intra.

| Asset | What it shows |
| --- | --- |
| `assets/open.mp4` | A photograph already open, then the arrow keys paging through the folder. |
| `assets/zoom.mp4` | Wheel zoom to 200%, a drag across the frame, then back to fit. |
| `assets/tree.mp4` | Ctrl+B opens the file tree; the panel is dragged wider; a subfolder expands. |
| `assets/video.mp4` | A video playing, the seek bar clicked, the chrome fading out when the pointer rests. |
| `assets/audio.mp4` | An audio file with cover art and the circular visualizer in the accent colour. |
| `assets/style.mp4` | Settings, then Terminal, then light mode, then back to Aurora: the window repaints each time. |
| `assets/rest.mp4` | The visualizer alone, no chrome. |

The pointer in every clip is drawn, not the mouse: the shoot tweens it and posts the
real input under it, so each move lands on the pixel it meant to.
